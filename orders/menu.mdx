Your menu is what Cortex uses to take accurate orders. A clean, well-structured
menu means fewer mistakes and faster calls. Manage it in the dashboard under
**Menu & FAQ → Menu**.

## Adding items

Hit **Add Item** to create a menu item. Each item has:

- **Name** — use the name your customers actually say.
- **Description** and **Ingredients** — help the agent answer "what's in it?"
- **Customization Notes** — how the item can be modified or special-cased.
- **Price** and **Category** — items are grouped by category (pick an existing
  one or create a new one inline).
- **Modifiers** — choices and add-ons, each with its own price (size,
  toppings, "no onions").
- **Available** toggle — flip it off to 86 an item without deleting it.

## Deploy to Voice Agent

<Warning>
  Menu edits don't reach the live agent until you press **Deploy to Voice
  Agent**. After any batch of changes, deploy — then place a test call.
</Warning>

The deploy syncs your items, prices, and modifiers to the agent so it takes
orders against the current menu.
