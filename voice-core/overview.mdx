Voice Core is the foundation of every Cortex agent — the phone number, the
voice, the hours it works, and the questions it can answer. Set this up first;
ordering and bookings build on top of it.

## Phone number options

- **New number** — provisioned instantly during onboarding. Best for a clean
  start or a dedicated ordering line.
- **Forward existing number** — keep the number customers already know; forward
  it to Cortex. See [Going Live](/going-live) for forwarding steps.

<Info>
  Want SMS confirmations and bookings over text? Your number needs A2P
  registration. We handle the filing for you during onboarding.
</Info>
