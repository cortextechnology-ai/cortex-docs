Support tickets live right in the dashboard — no separate help desk.

## Creating a ticket

Open **Support Tickets → Create Ticket**, or use **Report Issue** on any order
to file a ticket with the order and call context attached automatically.

Each ticket has a title, a category (**Billing**, **Bug**, **Order Issue**,
**Voice Agent**, **Feature Request**, **Other**), a priority (Low, Normal,
High, Urgent), and a description.

## Tracking tickets

The tickets list shows status at a glance: **Open**, **Waiting on You**, **In
Progress**, **Waiting on Support**, **Resolved**, or **Closed**. Open a ticket
to read and reply in its thread.

<Tip>
  For order problems, always start from the order's **Report Issue** button
  rather than a blank ticket — the attached call recording and transcript are
  usually exactly what we need to fix it fast.
</Tip>
